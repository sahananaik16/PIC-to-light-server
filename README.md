# PIC-to-light-server
In the PIC to Light project, the server validates the product ID to ensure that only authorized or correct product information is accessed or modified. When a user enters a product ID on the client side, the client sends this ID to the server via UART. The server then compares the received product ID with the stored product IDs in the system.If the entered product ID matches a valid entry in the server’s database, the server allows the client to update or view the corresponding universal stock number (USN) associated with that product. This enables the client to modify the inventory data, such as increasing or decreasing stock quantities, adjusting the details of the product, or querying the current stock levels.
If the entered product ID is incorrect or doesn't match any valid product, the server will deny the request and inform the client, preventing any unauthorized modifications to the inventory. The process ensures data integrity and secure management of the warehouse inventory, as only correct product IDs can modify the stock numbers, maintaining the accuracy and consistency of the system.Thus, the interaction between the client and server ensures that product management is secure, with precise control over which product data can be modified, based on validated product IDs.
